# 桌游规则记忆训练营

纯前端本地应用，在原有「桌游规则遗忘点卡片库」基础上扩展出规则记忆训练营。直接打开 `index.html` 即可使用，也可在本目录启动静态服务访问（`python3 -m http.server`）。

## 卡片库（原功能保持不变）

- 搜索、人数 / 复杂度筛选、按未玩时长排序
- 新增 / 删除桌游、封面图、四类规则（容易忘、常见争议、开局准备、计分提醒）的增删
- 「标记今天玩过」更新游玩日期
- 全部数据保存在浏览器 localStorage（键 `zfl18-boardgame-rule-cards`）；旧版字符串规则数据会自动迁移为带稳定 ID 的结构
- 所有日期（默认开始日期、标记今天玩过、新增表单默认值）均按**浏览器本地时区**计算，UTC+8 凌晨也不会落到前一天

## 规则记忆训练营

顶部切换「规则记忆训练营」标签进入。

### 计划生成

- 按**收藏内容、聚会人数、重点分类、可用天数**自动排程，每日包含**速记 → 问答 → 纠错**，并安排休息（每 4 天一个轻量休息日，训练日后附 5 分钟休息提示）
- 每天主打一款桌游，**同款桌游不连续两天复用**（强制错题复习除外，题库耗尽时会标注「同款连用」并提示）
- 调度优先级：答错次数与掌握度等级、错题状态、桌游整体提权、距上次游玩天数

### 答题与升降级

- 速记：先看规则再自评；问答：先回忆再看答案；纠错：错题再练
- **答错**：规则优先级上调、整张桌游提权、进入错题本，次日起到期，3 天内在到期日与到期 +2 日**至少复习 2 次**，复习满 2 次销账
- **连续答对 2 次**：规则降级，桌游提权回落

### 计划调整（变更后立即重排，时间不足会提示）

- 改人数 / 重点 / 每日题量 / 天数 / 开始日期
- 单日「换题」（在同一桌游内替换并固定）、「锁日程」（重排不影响该天）、「停一天」（当天不安排，可恢复）
- 到期错题挤占题量、窗口覆盖不完所有规则等情况都会给出「时间不足」提示

### 数据管理

- **撤销**：答题、换题、锁定、停一天、导入等操作均可逐步撤销（最多 30 步）
- **导出**：JSON 文件，含计划、会话、得分、错题、掌握度
- **导入**：按导出契约严格逐项核对（顶层 `app`/`version`，`training` 内 `config`/`plan`/`sessions`/`mastery`/`wrongs`/`seen`/`dayOverrides` 七个必需键），全部通过后才原子写入；缺字段（会提示字段名）、类型错误、结构不完整、引用失效等任何问题都不会覆盖原数据，提示会列出具体问题，会拦截：
  - 缺少任意必需字段或数组/对象（如缺少 `sessions`、`dayOverrides`、`version`、`training`、`config`）
  - 类型错误（数组写成字符串、`ok` 不是布尔、题量不是数字等）与非法/不存在日期（如 2026-02-30）
  - 失效桌游 / 已删除规则引用
  - 重复场次
  - 答案缺失
  - 场次时间冲突 / 计划日期重复
  - 非法 JSON、非法配置
  - 旧版字符串形式的 bans 仍可兼容导入
- **刷新恢复**：计划、会话、得分、错题全部持久化（键 `zfl18-camp`），重开页面自动恢复；收藏库删除规则后，训练营中的悬挂引用会被清理并重排

## 自动化验证

`verify.cjs` 为 Playwright 浏览器端到端验证（需 `npm install playwright && npx playwright install chromium`），覆盖：计划生成、题量/天数重排与时间不足提示、换题、锁定、停一天、答错提权、错题 3 天 2 次复习、复习销账、重点分类筛选、四类异常导入拦截与不覆盖、撤销、刷新恢复、旧数据迁移、原卡片库功能回归。`verify-regression.cjs` 额外用真实浏览器覆盖：Asia/Shanghai 凌晨本地日期（开始日期、标记今天玩过、表单默认值）与导入缺 `sessions`/类型错误/结构不完整等反例拦截。
